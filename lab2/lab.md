## 4. Запросы с агрегацией

Скрипт: [`aggregation-queries.sql`](aggregation-queries.sql)

| № | Описание | Функции |
|:---:|:---|:---|
| 1 | Количество постов в каждом блоге | `COUNT`, `ORDER BY` |
| 2 | Посты с более чем 2 лайками | `COUNT`, `HAVING` |
| 3 | Суммарные лайки по блогам | `COUNT`, `ORDER BY` |
| 4 | Среднее число комментариев на пост по блогу | `AVG`, `ROUND` |
| 5 | Количество подписчиков у каждого блога | `COUNT`, `ORDER BY` |
| 6 | Дата первого и последнего поста в блоге | `MIN`, `MAX` |
| 7 | Самые активные авторы (посты + комментарии) | `COUNT`, `ORDER BY` |
| 8 | Блоги с суммарными лайками > 5 | `COUNT`, `HAVING` |


## 5. Запросы с соединениями таблиц

Скрипт: [`join-queries.sql`](join-queries.sql)

| № | Описание | Тип соединения |
|:---:|:---|:---|
| 1 | Посты с блогом и автором | `INNER JOIN` |
| 2 | Пользователи и их блоги (включая без блогов) | `LEFT JOIN` |
| 3 | Посты с числом комментариев и лайков | `LEFT JOIN` + агрегация |
| 4 | Подписчики → блоги → владельцы | тройной `INNER JOIN` |
| 5 | Комментарии с именем автора и заголовком поста | `INNER JOIN` |
| 6 | Сводка по блогам: посты, лайки, подписчики | `LEFT JOIN` + агрегация |


## 6. Создание представлений

Скрипт: [`views.sql`](views.sql)

### `blog_stats` — статистика блога

Объединяет `blogs`, `users`, `posts`, `subscriptions`, `likes`.  
Показывает: владельца, число постов, подписчиков, лайков, дату последней публикации.

```sql
SELECT * FROM blog_stats ORDER BY total_likes DESC;
```

### `user_activity` — активность пользователей

Объединяет `users`, `blogs`, `posts`, `comments`, `likes`.  
Показывает: число блогов, постов, комментариев и лайков — удобно для рейтинга авторов.

```sql
SELECT * FROM user_activity ORDER BY posts_count DESC LIMIT 5;
```

### `post_details` — карточка поста

Объединяет `posts`, `blogs`, `users`, `comments`, `likes`.  
Показывает: пост, блог, автора, дату публикации, число комментариев и лайков.

```sql
SELECT * FROM post_details ORDER BY like_count DESC LIMIT 10;
```
